# 🎥 Camera Movement in Three.js

This project demonstrates smooth and interactive **camera movement** in a 3D scene using **Three.js**. It allows users to explore a 3D environment through intuitive mouse-based controls including orbiting, zooming, and panning.

## 🔧 Project Name

**CameraMovementThree**

## ✨ Features

- 📸 Interactive camera movement using `OrbitControls`
- 🖱️ Mouse-based rotation, zoom, and pan
- 🧭 View the 3D scene from multiple angles
- 🎯 Focused example for learning Three.js camera mechanics
- 🧹 Clean and minimal code structure

## 🛠️ Technologies Used

- **Three.js** – 3D rendering engine
- **JavaScript (ES6+)** – Logic and interactivity
- **WebGL** – Hardware-accelerated rendering
- **OrbitControls** – For camera interaction
